# Продолжить просмотр

Личный прогресс хранится отдельно от библиотеки в `zalip_watch_progress`:
последняя цель на пользователя/тайтл, каноническая серия, плеер/озвучка,
позиция и длительность, время последнего просмотра. Импорт, оценка, статус
списка, избранное, подписка и общий счётчик просмотренных серий не меняются.
Новая добавочная миграция: `1792257239060-ZalipWatchProgress.js`.

Приватные API `zalip/progress/show`, `start`, `update`, `continue`, `reset`
требуют штатной авторизации. Список выдаёт только опубликованные тайтлы
текущего пользователя, по последнему просмотру с keyset-курсором. Скрытый
тайтл не раскрывается; сброс собственного прогресса допустим и после его скрытия.
Удаление пользователя, тайтла или серии каскадно удаляет личную цель просмотра.
Сброс позиции скрывает запись и инвалидирует активную сессию, не трогая библиотеку.

`start` проверяет локальный snapshot плеера и доступность канонической серии,
создаёт новую серверную сессию. `update` принимает только её возрастающую
последовательность. Поздний запрос старой вкладки или после сброса не возвращает
старую позицию. Перемотка назад разрешена. Внешние API не запрашиваются при просмотре.
Изменившийся путь/ID версии Kodik обнуляет несовместимый таймкод; замена только
разрешённого домена зеркала позицию не сбрасывает.

На этом этапе точное время подтверждено только официальным Kodik JSAPI.
Сообщения принимаются от точного origin и текущего iframe WindowProxy;
при смене контекста старые обработчики и сессии не используются. Сохраняется
последний образец примерно раз в 15 секунд, при паузе/закрытии выполняется
best-effort отправка. Это не гарантия сохранения последней секунды при аварийном
закрытии браузера или потере сети. Возобновление требует нажатия пользователя:
просмотр страницы или URL не запускает видео и не применяет произвольный offset.

Для точной канонической серии Kodik включён официальный `only_episode=true`:
внутренний автопереход не может незаметно записать время другой серии.
Навигация серий остаётся в Zalip. Неизвестное внутреннее переключение блокирует
учёт времени с пояснением, не останавливая само видео. Для старого snapshot
без числового `providerTranslationId` точное время не приписывается: обновите
поле «Плееры» через импортёр. Raw ID озвучки при этом не изменяется.

Alloha и Collaps пока запоминают выбранную каноническую серию/плеер/озвучку
без обещания восстановления секунд: документированный контракт событий времени
не подтверждён. Тайтлы без канонических серий не получают выдуманные episode ID.
Просмотренное видео не переводит весь сериал в статус «Просмотрено».

Перед установкой нужны штатные резервные копии. Проверка миграции up/down/up
выполняется только на отдельно восстановленной БД; на production down не запускается.
